Lesson 0010 · 70 分钟 · 25 题

身强身弱：像侦探一样称证据

不数人头，不凭月令一票定输赢。用固定顺序调查两张对比命盘，再处理一张证据冲突、必须保留“不确定”的命盘。

知识地图

定位日主与月令
→ 展开藏干、查根
→ 标出生扶与泄耗克
→ 比较证据质量，不数字数
→ 初判偏强／偏弱／待定
→ 写反证与复核点
侦探五问：什么天气？脚下有根吗？队友来了谁？力量流去哪？有没有关键反证？

一、标准调查流程

  1. 月令定背景：日主在时令中旺相休囚死。
  2. 地支查根：同类是否藏在四支，主气还是余气，是否重复。
  3. 天干查助：比劫、印星是否透出。
  4. 检查泄耗克：食伤、财、官杀是否成势。
  5. 写双向证据：支持与削弱都必须写，禁止只找支持自己结论的材料。
  6. 暂定等级：明显偏强、偏强、待定、偏弱、明显偏弱。

结论必须带“因为”和“但是”：因为哪些关键证据，所以暂判什么；但是哪项反证可能修正。

二、案例 A：支持成群

壬子　乙卯　甲寅　癸亥｜甲木日主

层证据方向
令卯月春木旺强支持
地卯藏乙、寅藏甲、亥藏甲多处木根
助乙劫财；壬癸印星；子亥水生木生扶集中
泄耗克明干无火土金；地支亦少明显通道削弱有限

初判：明显偏强。关键不是“水木字多”，而是卯月得时、多根、比印集中，且缺少有效泄耗克。后续仍需检查合冲与行运。

三、案例 B：失令无根，泄耗克集中

庚申　戊申　甲午　丁巳｜甲木日主

层证据方向
令申月秋金旺，木在时令处死地明显削弱
地申申午巳藏干中无甲乙无木根
助申中藏壬印，但未透且受整体金火土环境影响有限支持
泄耗克丁火泄、戊土耗、庚申金克；巳午火又泄多路削弱

初判：明显偏弱。反证是申中两见壬水印星；但它深藏未透，暂不足以推翻失令、无根与多路泄耗克。

四、案例 C：证据打架，允许待定

辛酉　丙辰　癸未　丁巳｜癸水日主

  • 支持：辛酉金印生水；辰中藏癸，为日主根。
  • 削弱：丙丁巳火为财耗；辰未土为官杀克水。
  • 复杂处：辰月是季节转换土，寒暖湿燥与藏干层次不能只用粗表处理。

初判：待定，偏弱风险较高。可以指出削弱面较显，但在未学习节气深浅、合冲制化前，不强行给“必弱”结论。

高手不是每盘都秒答。证据冲突时敢写“待定＋缺什么”，比硬猜更专业。

五、为什么不能数字数

案例 B 虽然申中两藏壬水，看似有两个印；但月令、根气、透藏与整体流向不同，不能把“两个壬”与一个月令庚金或一个明透丁火按一票等权。传统命理文本本身也有“得时不旺、失时不弱”的提醒，意在反对单一条件机械决定。《滴天髓》

七、案例 A 深挖 7 分

  1. 甲木在卯月处什么状态？
  2. 列出全部木根。
  3. 明干有哪些比劫或印？
  4. 地支有哪些印星？
  5. 主要泄耗克通道是否明显？
  6. 写一个反证。
  7. 用“因为—但是—所以”写结论。
展开参考答案
  1. 旺；春木当令。
  2. 卯藏乙、寅藏甲、亥藏甲。
  3. 乙为劫财；壬癸为偏印、正印。
  4. 子藏癸，亥藏壬。
  5. 不明显；明干与主要支气集中在水木。
  6. 可写“仍需检查后续合冲和运年是否引出泄耗克”；原局直接反证较弱。
  7. 因为卯月得时、多根、比印集中，且削弱通道有限；但是组合制化尚未细查；所以暂判明显偏强。

八、案例 B 深挖 7 分

  1. 甲木在申月处什么状态？
  2. 四支是否有木根？
  3. 列出明干泄耗克。
  4. 巳午对甲木主要属于哪类作用？
  5. 申中壬水属于哪类支持？
  6. 为何壬水反证暂不足翻盘？
  7. 用“因为—但是—所以”写结论。
展开参考答案
  1. 死；秋金当令，木处死地。
  2. 没有。申、申、午、巳藏干均无甲乙。
  3. 丁为伤官泄；戊为偏财耗；庚为七杀克。
  4. 火为食伤，属于泄身。
  5. 印星生扶。
  6. 壬藏于申而未透，且全局失令无根、泄耗克成群，支持质量有限。
  7. 因为失令无根，火土金泄耗克集中；但是申中壬印提供有限生扶；所以暂判明显偏弱。

九、方法纠错 6 分

  1. “同类三个、异类五个，所以身弱。”纠错。
  2. “得令就不用看根。”纠错。
  3. “无根必从弱。”纠错。
  4. “偏强就是好命。”纠错。
  5. 一份合格结论为何必须写反证？
  6. 案例 C 还缺哪些后续知识才能更稳地复核？
展开答案
  1. 数量未体现月令、位置、主余气、透藏、受制与组合。
  2. 得令只是天气层；根气与生扶、泄耗克仍能修正。
  3. 从格有更严格条件，不能由“无根”单点跳结论。
  4. 强弱是力量状态，不是人生好坏评分。
  5. 防止确认偏误，让判断可复核，并指出结论边界。
  6. 节气深浅、辰土性质、干支合冲刑害、制化及更完整的调候知识。

评分与结业门槛

23–25 达标。漏证据层：用证据表重做。只写单向证据：强制增加反证栏。强行二选一：练习使用“待定、倾向、复核点”。
