Lesson 0013 · 55–65 分钟 · 20 题

刑、害、破：先拆术语，再记关系表

先定义、再推导；把助记、结构事实与作用判断分清楚，用练习形成可核对的输出。

知识地图

已学合冲 → 增加刑害破关系层
单对／三支组／重复支 → 分别识别
保留同时关系 → 不自动推现实事件

字面很重，含义先放回关系表

刑、害、破都是传统地支关系名。本课用“刑像牵制、害像不协调、破像破损”帮助认字，但它们不等于刑罚、伤害或破产事件。一个字面不能代替判断条件与现实证据。

先修第十一、十二课。本课采用常见子平刑害破表；不同流派对三刑齐全、两字成刑、自刑次数及作用权重有争议。我们明确只识别表中关系，不用单条断语预测事件。

刑：两字、三字、重复字分开记

类别常见成员／方向本课记录口径
子卯子卯相刑两不同支出现，记子卯关系
寅巳申寅刑巳、巳刑申、申刑寅三成员齐全才写三刑组齐全；两字写组内关系线索，不冒称完整三刑
丑戌未丑刑戌、戌刑未、未刑丑同样分完整组与两字线索
自刑辰辰、午午、酉酉、亥亥同一支至少两处重复，记自刑候选；不从一处辰推自刑成立
两字：子 ↔ 卯
三支：寅 → 巳 → 申 → 寅
三土：丑 → 戌 → 未 → 丑
重复候选：辰辰／午午／酉酉／亥亥
按“一个两字组、两个三字圈、四个重复支”分袋记。三土圈是丑戌未，别把辰补进去；辰属于自刑候选的单独袋。

上述方向是常见表述；各派对两字能否单独论刑和自刑成立有不同限制。本课候选清单不等于已经发生作用。巳申可同时见六合与刑组线索；不允许因一项已存在就删另一项。

六害：从六合伙伴与六冲伙伴搭记忆桥

子未　丑午　寅巳
卯辰　申亥　酉戌

可用“冲了我的六合伙伴”复现六害表。例如子合丑，丑冲未，于是子未是害对；卯合戌，戌冲辰，于是卯辰是害对。只需回第十一课两张已学表。

先找合伴，再找合伴的冲伴：害对＝冲其合伴的那个支。这个两跳检索法恰好复现六害表；不是事件机制的证明，也不表示一方主观上要伤害谁。

例：寅合亥，亥冲巳，故寅巳害。反例：寅申是冲，不是害；不能把“克制很强”都写成害。

六破：没有万能数格法，按熟悉关系分袋

配对检索袋
子酉、卯午四旺交叉两对
辰丑、未戌四墓库两对
寅亥、巳申与六合表重合的两对
旺支两对、库支两对、合表两对：子酉卯午，辰丑未戌，寅亥巳申。逐对背，不能把袋内四字任意排列配对。

破与合可以在同一对出现，如寅亥既是六合又在六破表。不同流派对破的权重和重合解释不同；本课保持两项原始标签，不判相互抵消。没有简单可靠的统一数格法时，分类比硬造口诀更稳。

制作关系清单，不制作恐惧清单

  1. 从四支逐对查刑组线索、六害、六破。
  2. 查三刑是否三个不同成员齐全，查自刑候选是否同字至少两处。
  3. 写双方或各成员柱位，保留已经识别的合冲会。
  4. 区分候选与实际作用；回到时令、藏干与证据质量，不删除原有支持证据。

示范（单层练习）：年寅月巳日申时亥：寅巳申刑组成员齐全；害对寅巳、申亥；破对巳申、寅亥。同时还存在寅申冲、巳亥冲、寅亥合、巳申合。先写全，不按标签数量打凶分。

反例：把三种关系都出现写成“三倍危险”没有依据。同一组字产生重叠标签，不能当三条独立灾祸证据。

识别题 5分，每题1分

1. “刑”在本课首先是什么？

2. 哪支属于常见自刑候选？

3. 子合丑、丑冲未，可记哪一害对？

4. 哪对既在六合也在六破表？

5. 只有丑戌，是否写三刑成员齐全？

推导题 5分，每题1分

  1. 从午的六合伙伴推出害对。
  2. 从申的六合伙伴推出害对。
  3. 写出寅巳申常见刑向圈。
  4. 按三个记忆袋写六破。
  5. 辰只有一处，另一处午，为什么不写辰自刑？
展开逐题答案与理由
  1. 午合未，未冲丑，故午丑害。
  2. 申合巳，巳冲亥，故申亥害。
  3. 寅刑巳、巳刑申、申刑寅；两字线索与完整组须分开。
  4. 旺袋子酉、卯午；库袋辰丑、未戌；合袋寅亥、巳申。
  5. 自刑候选要求同支重复；辰午不是辰辰或午午。

纠错题 5分，每题1分

  1. “四库都是三刑成员。”纠错。
  2. “寅亥合，所以不可能破。”纠错。
  3. “两处子，所以自刑。”纠错。
  4. “有害就有人要害我。”纠错。
  5. “冲刑害三个标签，凶分乘三。”纠错。
展开逐题答案与理由
  1. 三土刑组为丑戌未，不含辰；辰属于常见自刑候选。
  2. 本表寅亥同时六合与六破；两标签保留，作用权重另判。
  3. 子不在辰午酉亥候选表；重复本身不推出本课自刑。
  4. 传统关系名不表示他人动机；必须与现实证据分开。
  5. 重叠标签常由同组字产生，不是独立等权事件证据。

迁移题 5分，每题1分

  1. 年辰月酉日辰时午，自刑候选在哪两处？
  2. 年丑月戌日未时辰，列完整三刑与六破。
  3. 年子月卯日未时午，列本课子参与关系。
  4. 原局寅申，流年巳来到，如何写三刑？
  5. 示范一条无事件断语的刑害破记录。
展开逐题答案与理由
  1. 年辰与日辰重复，记辰辰候选；午酉各一次，不写午午酉酉。
  2. 丑戌未三刑组齐；未戌、辰丑为破；另辰戌冲、丑未冲须保留。
  3. 子卯刑、子未害；子午冲属十一课一并保留。没有子午破。
  4. 原局寅申为组内线索缺巳；该流年加入巳后三成员条件齐，不改写原局。
  5. 例：年寅与时巳见寅巳刑组线索和害，缺申未写完整三刑；位置已记，作用需复核，不能断刑罚或伤害。

评分、复述与间隔复测

20题，每题1分；书写题结论和理由都正确才得分。18–20分达标，且第11–15题的边界纠错须全对；15–17分先重做错题组；低于15分重画关系图。

错1–5回术语与表；错6–10重走记忆结构；错11–15写一条正确规则及一个反例；错16–20补位置、时间层与未确认条件。24小时后遮表复述，48小时后换成员或例子再做迁移。

一分钟闭卷复述：说明本课术语、表的结构、记忆方式、适用范围及一个不能推出的结论。只会报名称、无法给理由时，不算掌握。

本课输出：刑害破分袋卡，一份标完整组、两字线索、自刑候选及交叠关系的柱位表。

本课采用明确写出的常见子平关系表，不统一未说明的作用权重。助记图是检索工具，不冒充自然规律或原典证明；单层或局部条件例题非已核历法出生盘。原典对读：《渊海子平》干支组合相关篇目。传统解释不保证现实预测，不能替代医疗、法律或投资判断。
