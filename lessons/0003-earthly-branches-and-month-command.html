十二地支：先读季节，再谈月令

把十二支组织成四季、四组三会序列与五行分布；同时建立关键边界：八字月份按节气换月，不按农历初一。

知识地图

十二地支 → 四季三支
季节 → 五行主气
月支 → 月令入口
节气边界 → 正确排月柱
月令 → 后续旺衰与格局

先搭逻辑桥：季节位置与支的阴阳是两张表

“月令”的令表示时令背景；“月支”是月柱的地支。季首、季中、季末是季节位置；阳支阴支是另一套固定序列，不能由位置直接推阴阳。

四季三格 → 确认月支位置 → 再查阴阳 → 核对交节
先画四行三格，再另写子丑寅卯辰巳午未申酉戌亥，逐个标阳阴。不要在季节图上强套“第一格都阳”。

走一遍：巳在夏季第一格，但按子起交替序列为阴支；午第二格反而是阳支。

反例与边界：“四生全阳、四旺全阴”错：巳亥阴，子午阳。藏干组的阴阳不能代替地支阴阳。

一分钟闭卷复述：为什么冬季顺序是亥子丑，而固定十二支序列从子开始？

一个是按季节换组，一个是固定符号顺序；用途不同，冬季仍从立冬亥月开始。

此处复述不计入原有题目总分。学后即刻复述，24 小时后遮表重做，48 小时后换起点或换例子；只会背结论但说不出步骤，回本节再练。

一、先背四季骨架

季节三个月支主五行结构
春寅 卯 辰木季首、季中、季末
夏巳 午 未火季首、季中、季末
秋申 酉 戌金季首、季中、季末
冬亥 子 丑水季首、季中、季末

每季第三支辰、未、戌、丑都属土，用来承接季节转换。于是地支五行可压缩为：

亥子水；寅卯木；巳午火；申酉金；辰戌丑未土。

先把名称讲清楚：从四季纵向取组

第三课已学四季各有三个月。现在把每季的第一、第二、第三个月分别放在一起；“四”就是四季各取一个。

春：寅 → 卯 → 辰
夏：巳 → 午 → 未
秋：申 → 酉 → 戌
冬：亥 → 子 → 丑
纵向：四生　四旺　四季土
名称成员名称的含义
四生寅、巳、申、亥“生”指长生，即传统五行气开始生发的阶段。四支恰在季首，但不是各自本气都在此长生。
四旺／四正卯、午、酉、子“旺”指木火金水各在相应季节的旺盛位置；“正”关联东南西北四个正方位。两个名称在本课指同一组。
四墓库辰、未、戌、丑“墓”指传统十二阶段中气归藏的阶段；“库”取收藏之意。这组也叫四季土，均属土。不能从名称直接推出吉凶或“逢冲必开库”。

注意三个字：生＝生发，旺＝旺盛，库＝收藏。“四墓”与“四库”指同一组；“四旺”与“四正”指另一组。这里先学名称和表，不展开完整十二长生或墓库取用争议。

先记分组名称即可；这些支为何藏不同天干，在第四课及第四课藏干记忆展开。

二、地支阴阳

按地支固定顺序交替：子阳、丑阴、寅阳、卯阴……戌阳、亥阴。

阳支子 寅 辰 午 申 戌
阴支丑 卯 巳 未 酉 亥
阴阳与五行是两个坐标。午是阳火，巳是阴火；不能看到“火”就默认都阳。

三、月令不是农历月份标签

命盘中的月支通常称月令，是观察出生时令的重要入口。子平传统强调日干为主、月令为提纲。《渊海子平》

节气起点月支节气起点月支
立春寅立秋申
惊蛰卯白露酉
清明辰寒露戌
立夏巳立冬亥
芒种午大雪子
小暑未小寒丑

实务规则：出生在交节当天，必须核对当年该节气的精确时刻与出生地／时区；不能只看日期猜月支。本课学会读已排好的月令，不手算月柱。

四、三层信息不要混

  1. 月支事实：命盘月柱下方是什么支。
  2. 季节归类：该支属于哪一季、哪个五行阶段。
  3. 旺衰推断：必须结合日主、透藏和全局；本课暂不下结论。

例如月支酉：事实是“酉月”；归类为秋季、金；但不能据此直接断“金日主一定旺”。那需要后续完整证据。

  1. 巳午未＝哪一季？
  2. 申酉戌＝哪一季？
  3. 亥子丑＝哪一季？
  4. 卯＝阴阳＋五行？
  5. 午＝阴阳＋五行？
  6. 申＝阴阳＋五行？
  7. 亥＝阴阳＋五行？
  8. 清明起是什么月支？
  9. 白露起是什么月支？
  10. 小寒起是什么月支？
展开答案与依据
  1. 夏；巳午未。
  2. 秋；申酉戌。
  3. 冬；亥子丑。
  4. 阴木；寅卯属木，卯为阴。
  5. 阳火；巳午属火，午为阳。
  6. 阳金；申酉属金，申为阳。
  7. 阴水；亥子属水，亥为阴。
  8. 辰月；春季第三月。
  9. 酉月；秋季第二月。
  10. 丑月；冬季第三月。

七、实务迁移 5 分

  1. 命盘月柱“辛酉”：写出月令、季节、主五行。
  2. 命盘月柱“戊辰”：能否只凭辰月说戊日主一定旺？
  3. 出生在立春当天，为什么不能只凭“当天日期”决定寅月或丑月？
  4. 把十二月支按春夏秋冬完整写出。
  5. “农历二月一定是卯月”为什么不够严谨？
展开参考答案
  1. 月令酉；秋季；金。
  2. 不能。辰属土只是证据之一，还要看交节深浅、透藏、通根、全局生克等。
  3. 换界发生在当年立春的精确时刻；出生可能在交节之前或之后。
  4. 寅卯辰；巳午未；申酉戌；亥子丑。
  5. 八字月支按节气换界，不按农历初一；交界附近尤其可能不同。

评分与补救

18–20 达标。错季节：重写四组三支。错阴阳：从子开始交替标记。错换月：重看节气表。低于 15 分，不进入藏干。
