Lesson 0014 · 55–65 分钟 · 20 题

组合复核：把关系清单接回旺衰证据

先定义、再推导；把助记、结构事实与作用判断分清楚，用练习形成可核对的输出。

先回接已学，再决定哪些问题暂缓

第8–10课提供月令、根与生扶／泄耗克证据，第11–13课提供关系标签。本课只练把新标签接回旧证据；不要求会取用神、格局或高级转化条件。“同源”指多个标签来自同一组字；“反证”指盘面上与当前倾向相反的具体依据。

先口答再展开：“冲了，所以删寅甲”跳过哪一步？

把尚未确认的作用假设当成事实，省略条件检查；寅的藏干表不因此删除。

知识地图

第十课初判 → 十一至十三课关系清单
同一位置多标签 → 去除重复计票
事实／作用假设／复核条件 → 三栏记录
保留反证 → 更新倾向与不确定性

复核是什么，后面的进阶问题先不展开

复核就是重新检查：新增的关系标签，会不会影响原来列出的具体支持或制约证据？本课只记录、提出假设并检查条件。进阶的整体配置、取用和转化规则尚未授课，因此这里不靠新名词作判断。

本课先修第九至十三课，目标是完成可追溯复核，不建立通用于所有盘的组合优先级，不判断从格、不保证合化、不直接选择用神。多重关系的实际权重有流派条件，未说明条件的地方保持待定。

事实、作用假设、验证条件分三栏

层该写什么不该偷渡什么
事实月支、藏干、透干、原表配对与柱位根已没、必化、一定吉凶
作用假设可能牵连某根气、生扶或泄耗克通道把可能写成已证实
复核条件时令、位置、得根、透藏、对方力量、口径与时间层不说明依据就定权重
先“是什么”，再“可能怎样”，最后“凭什么确认”。三栏记成“事实—假设—条件”；每个假设必须指向具体字和条件。

例：寅申冲是事实；“寅中木根作用可能受牵连”是假设；检查时令、位置、双方支持才是复核任务。反例：“冲了，根消失”把后两栏直接删了。

顺序是检查顺序，不是力量优先级

定位与历法 → 令地助／泄耗克初表
→ 合冲会刑害破清单
→ 标交叠、同源与时间层
→ 提作用假设及最强反证
→ 能确认的修订／不能确认的待定
  1. 先核排盘与时区交节；未经核验只称教学组合。
  2. 保留第十课初判的依据，不因新关系名出现就全推翻。
  3. 标出新增关系牵连的具体证据，例如哪处同类根、哪个印星。
  4. 把同一支的季节支持、根气与多个关系标签注明同源，不能等权叠加。
  5. 记录最强反向证据及缺失条件；只有足够依据才改倾向，否则写待定。

先查三会再查六合只是清单顺序，不代表三会在每个盘里都压过六合。位置远近可以记录为事实，但不能无说明地套“隔柱完全无作用”等一刀切规则。

三个反事实对照：一次只改一个条件

情境A：已知甲木日主、卯月，支见寅，同类根与得时是初步支持；若再见申，增加寅申冲和申内庚壬戊，不删寅甲。仍缺全盘，不能立刻从偏强改明显偏弱。

情境B：把申换成子，新增子癸印生扶，寅申冲不再存在；不代表A与B其余力量完全相同。此对照只帮助识别新输入改变哪些证据。

情境C：原局只申子，某流年见辰：完整水组条件出现在该时间层。原局水组缺辰仍是真实记录；流年到来也不保证永久化水。

三情境只是局部条件练习，缺四柱全貌，不当作完整出生盘。它们的正确输出是证据变化表，而不是必强、必弱、某年必发生某事。

怎样写可以被别人核对的结论

“因为……暂倾向……；但是……；若要确认，需要……。”因为至少连两项具体证据，但是列原局反证；缺资料写缺什么，未来事项放复核栏。

例：“甲木在卯月得时、寅藏甲提供根线索，支持面可见；但是申与寅形成冲且申藏庚壬戊，作用方向须逐项评估。因资料仅局部，暂不定全盘强弱，需补完整明干、四支与其他支持通道。”

表达限制不等于什么都不做：具体藏干、配对和位置仍可检查。未知实际作用时，先产出完整清单与假设，再把下一步问题写清楚。

识别题 5分，每题1分

1. “寅申冲”属于哪栏？

2. 同一寅参与冲与刑线索，如何计证据？

3. 检查表顺序是否等于力量排名？

4. 资料只给日主、月支和两支，可否定全盘旺衰？

5. 流年字加入组合，放在哪层？

推导题 5分，每题1分

  1. 把“卯月甲木，寅藏甲”分别写入证据层。
  2. 新增申后，至少列三项结构变化。
  3. 申换子后，明确删除与增加什么事实。
  4. 子丑午未同时合冲时，如何区分事实与假设？
  5. 原局申子与流年辰分别怎样记？
展开逐题答案与理由
  1. 卯月时令支持写令，寅甲同类根写地；两者来源明确，不写独立等权分数。
  2. 有寅申冲；申藏庚壬戊；相对甲庚克、壬助、戊耗。实际权重待复核。
  3. 目标关系寅申冲不再存在；子藏癸印生扶增加。保留其余已知条件，不保证结论必反转。
  4. 事实两合两冲及位置；假设某些证据可能受牵连；条件检查时令、力量、距离和具体口径。
  5. 原局缺辰；流年辰加入后的三合完整成员条件单列，不预判成化。

纠错题 5分，每题1分

  1. “先查三会，所以三会永远最强。”纠错。
  2. “冲掉甲根，因此把寅藏甲删掉。”纠错。
  3. “原局没有反证，就把未来冲根写原局反证。”纠错。
  4. “日主偏强，所有泄耗克都喜。”纠错。
  5. “刑害破三个标签就是三次灾。”纠错。
展开逐题答案与理由
  1. 步骤是完整性检查顺序，不是普适力量排序。
  2. 藏干对应事实不删除；根气是否受制、程度多大另列假设与条件。
  3. 原局反证必须来自现有盘；未来冲根是时间层复核事项。
  4. 强弱不是完整喜忌；还未学习完整的取用判断规则，不能只按生扶或泄耗克一刀切。
  5. 关系标签非事件次数，同源交叠不可独立加票，更无现实灾祸保证。

迁移题 5分，每题1分

  1. 有人只报甲日主卯月寅申，写最短合格结论。
  2. 对同一局部例写一个作用假设和两个条件。
  3. 写子丑午未局部支序的事实清单，不下吉凶。
  4. 为复核表写三列标题，并填寅申一行。
  5. 用一分钟说明为什么复核后仍可待定。
展开逐题答案与理由
  1. 有得时和寅木根支持，同时寅申冲及申藏干需复核；资料不完整，暂不定全盘强弱。
  2. 假设寅根作用受申关系牵连；查寅申位置及双方得时生扶力量。假设不写已确认。
  3. 子丑、午未合；子午、丑未冲；子未、丑午害。具体柱位按输入记录，不保证合化或凶。
  4. 事实：寅申冲及柱位；假设：木根作用可能受牵连；条件：时令、支持、位置及完整盘信息。
  5. 能确认表与位置，但实际作用所需力量条件不足或证据相反；待定必须说明缺什么并给下一步检查。

评分、复述与间隔复测

20题，每题1分；书写题结论和理由都正确才得分。18–20分达标，且第11–15题的边界纠错须全对；15–17分先重做错题组；低于15分重画关系图。

错1–5回术语与表；错6–10重走记忆结构；错11–15写一条正确规则及一个反例；错16–20补位置、时间层与未确认条件。24小时后遮表复述，48小时后换成员或例子再做迁移。

一分钟闭卷复述：说明本课术语、表的结构、记忆方式、适用范围及一个不能推出的结论。只会报名称、无法给理由时，不算掌握。

本课输出：一张事实／作用假设／复核条件三栏表，一段带具体依据、反证与缺失条件的结论。

本课采用明确写出的常见子平关系表，不统一未说明的作用权重。助记图是检索工具，不冒充自然规律或原典证明；单层或局部条件例题非已核历法出生盘。原典对读：《渊海子平》干支组合相关篇目。传统解释不保证现实预测，不能替代医疗、法律或投资判断。
