藏干是什么

四柱表面只有四个天干、四个地支。传统子平法还把每个地支展开为一至三个天干，用于描述支内的五行成分。

地支子寅酉巳
藏干癸甲 丙 戊辛丙 戊 庚

《渊海子平》保存了“地支藏遁歌”，如“子宫癸水在其中，丑癸辛金己土同；寅宫甲木兼丙戊，卯宫乙木独相逢”。原典

先把名称讲清楚：从四季纵向取组

第三课已学四季各有三个月。现在把每季的第一、第二、第三个月分别放在一起；“四”就是四季各取一个。

春：寅 → 卯 → 辰
夏：巳 → 午 → 未
秋：申 → 酉 → 戌
冬：亥 → 子 → 丑
纵向：四生　四旺　四季土
名称成员名称的含义
四生寅、巳、申、亥“生”指长生，即传统五行气开始生发的阶段。四支恰在季首，但不是各自本气都在此长生。
四旺／四正卯、午、酉、子“旺”指木火金水各在相应季节的旺盛位置；“正”关联东南西北四个正方位。两个名称在本课指同一组。
四墓库辰、未、戌、丑“墓”指传统十二阶段中气归藏的阶段；“库”取收藏之意。这组也叫四季土，均属土。不能从名称直接推出吉凶或“逢冲必开库”。

注意三个字：生＝生发，旺＝旺盛，库＝收藏。“四墓”与“四库”指同一组；“四旺”与“四正”指另一组。这里先学名称和表，不展开完整十二长生或墓库取用争议。

为什么“四生”不是本气的出生地

藏干是传统体系规定的对应表，不是凭一个口诀就能证明的自然规律。我们用季节和生旺墓结构理解表，再用口诀复现表；两步要分开。

本课采用常见的阳干长生定位：木长生在亥，火在寅，金在巳，水在申。所以寅虽是春季木支，却称火的长生地；亥虽是冬季水支，却称木的长生地。这解释了四生为何同时藏有另一行的阳干。

支本气：当前季节生发之气另外的土气课程藏干表
寅甲木丙火：火长生在寅戊甲 丙 戊
巳丙火庚金：金长生在巳戊丙 戊 庚
申庚金壬水：水长生在申戊庚 壬 戊
亥壬水甲木：木长生在亥无：本表亥不藏戊壬 甲

土没有独立的第五个季节。传统有土寄于四时、土随火等解释口径；本课不据此强推所有支都应藏土，而以藏干表为准：寅巳申带戊，亥不带。巳写丙戊庚，是沿用本课表序；先找到成员，再按表序写回。

四生如何“隔两个”记

先画甲 → 丙 → 庚 → 壬 → 甲的阳干圈（木火金水，先把土拿开）。每支取“本气＋圈里下一位”；寅巳申再加戊，亥不加土。最后恢复表序。
寅：甲 → 丙 ＋ 戊＝甲丙戊
巳：丙 → 庚 ＋ 戊＝丙戊庚
申：庚 → 壬 ＋ 戊＝庚壬戊
亥：壬 → 甲　　 ＝壬甲

如果用十干顺序甲乙丙丁戊己庚辛壬癸数，“向前两个”在这里约定为沿箭头走两格，不把起点算一格，末尾回到甲。寅的甲→丙→戊、巳的丙→戊→庚确实连续隔两格；但申若照搬会得到庚壬甲，亥若照搬会多出丙，都不符合本表。

口诀适用范围：四生藏干都是阳干，不等于四生地支都是阳支。巳、亥是阴支。十干数格法只直接覆盖寅、巳；完整四生用“阳干圈＋戊土例外”。

四旺先取阴干，午多一个己

第三课的季节主行是木、火、金、水。四旺位取对应的阴干：卯乙、午丁、酉辛、子癸；午再藏己。午中己土可联系火土相随理解，但这是传统表的特殊项，不能把所有四旺都加土。

按季节说卯乙、午丁己、酉辛、子癸；先记四个阴主气，再单独补“午有己”。

“都是阴的”说的是藏干。午、子仍是阳支，支的阴阳与藏干阴阳不能互相替代。若把四旺误叫“四墓”，就会把两组混在一起。

四库为何各有三个干

先把季末拆成三层：土本气＋刚过去季节的余气＋所收藏五行的气。余气取阴干，库气也取阴干。这里“余气”是帮助理解的季末残留；本课不把每种附藏干都笼统称为同等力量的余气。

库的对应由常见木火金水生旺墓链定位，不是“春末一定是木库”：

木：亥（生）→ 卯（旺）→ 未（墓库）
火：寅（生）→ 午（旺）→ 戌（墓库）
金：巳（生）→ 酉（旺）→ 丑（墓库）
水：申（生）→ 子（旺）→ 辰（墓库）

这四组三支也常称三合组；本课只借位置理解墓库，不因此判断命盘已经合化。阴干十二长生在不同口径下另有顺逆排法，不能拿本节阳干定位去替代它。

季末支土本气本季余气（阴干）库气（阴干）结果
辰：春末、水库戊春木乙水癸戊 乙 癸
未：夏末、木库己夏火丁木乙己 丁 乙
戌：秋末、火库戊秋金辛火丁戊 辛 丁
丑：冬末、金库己冬水癸金辛己 癸 辛
土坐中间，季尾留阴，库里再取阴。辰戌用戊，丑未用己。阴干圈：乙 → 丁 → 辛 → 癸 → 乙；从季节余气往箭头反方向走一位，就是库气：乙←癸、丁←乙、辛←丁、癸←辛。

这比含糊的“往后数两个”更稳：在完整十干序列里，乙往回两格得癸、丁得乙、癸得辛，但辛往回两格是己而不是丁。要先排除土，再在木火金水的阴干圈倒退一位。这是对已知藏干表的助记压缩，不是墓库理论的证明。

从一个字还原到整张表

  1. 放回四季三格图，先判四生、四旺或四墓库。
  2. 四生：本气阳干＋阳干圈下一位，寅巳申加戊；四旺：本气阴干，午加己。
  3. 四库：先写土本气，再写本季阴余气，沿阴干圈倒退一位取库气。
  4. 恢复课程表序；巳尤其记为丙戊庚。与总表核对，再谈透干和根。

正例：未在夏末→四库→阴土己＋夏火丁＋丁在阴干圈的前一位乙→己丁乙。

反例：“辰在春末，所以辰是木库，藏戊乙甲。”错在把余气与库气混同：春木余气是乙，辰为水库，库气是癸；应为戊乙癸。

闭卷复述：盖住表，用一分钟说出三个组名的含义、各自成员、两条干圈和午／亥例外；再画四季十二格，填满藏干。助记故事可以叫“季节房间里的住客”，但住客比喻不代表真实物质或力量百分比。

本课程按主气在前记录。先准确展开，不在本课给藏干打百分比；各派司令天数与权重口径不同，过早混入只会制造假精确。

藏、透、根：三个层次

例盘：甲子　丙寅　辛酉　癸巳。

  1. 藏：寅中藏甲丙戊。
  2. 透：寅中甲、丙同时出现在四柱天干，称甲、丙透出；戊未透。
  3. 根的线索：辛日主在酉支见辛，说明日主在地支有同类根气。强弱程度仍需后课结合月令与全局。

“有藏干”不等于“力量相同”；“透出”也不自动等于吉或凶。本课只做结构识别，不提前下旺衰结论。

标准展开算法

1
抄出四个地支，保留年、月、日、时位置。
2
逐支查表展开藏干，主气写在第一位。
3
把所有藏干与四个天干逐字比对，标出哪些“透”。
4
检查日主同类是否藏于任何地支，只记“有／无根线索”，暂不打分。

2. 寅为何列入四生？

4. 辰是什么库？

5. 哪个四旺要另补土？

推导题 5 分，每题 1 分

  1. 用阳干圈还原申。
  2. 用规则还原亥，并说明为何不补戊。
  3. 用季末三层法还原辰。
  4. 用季末三层法还原戌。
  5. 还原巳，解释为何最终写丙戊庚。
展开逐题答案与理由
  1. 申本气庚，下一位壬，加戊，得庚壬戊；不能沿十干圈补甲。
  2. 本气壬，阳干圈下一位甲，得壬甲；本表亥不藏土，必须单记此例外。
  3. 春末辰：土本气戊＋春木阴余气乙＋水库阴气癸＝戊乙癸。
  4. 秋末戌：戊＋秋金辛＋火库丁＝戊辛丁。阴干圈跳过己，从辛倒退一位到丁。
  5. 本气丙＋阳干圈下一位庚＋戊；成员是丙庚戊，按课程表序记录丙戊庚。

纠错题 5 分，每题 1 分

  1. “四生都是阳支，所以藏阳干。”错在哪里？
  2. “四库都是阴干。”改成准确说法。
  3. “寅甲丙戊，所以申庚壬甲。”怎样纠正？
  4. “辰是春末，当然是木库。”哪两件事混了？
  5. “库像仓库，冲开一定发财。”能从本课推出吗？
展开逐题答案与理由
  1. 支阴阳与藏干阴阳是不同坐标；巳亥为阴支。四生藏阳干是表的规律，不能从支阴阳推出。
  2. 两项附藏干均为阴干；土本气辰戌为阳戊，丑未为阴己。
  3. 十干连续隔两格只覆盖寅巳；申取庚壬后补戊，得庚壬戊。
  4. 季末余气与库气混了：辰留春木乙，但水的墓库是辰，故另藏癸。
  5. 不能。仓库只是助记比喻，本课只识别藏干结构，不涉及冲开库的条件、取用或现实财富。

迁移题 5 分，每题 1 分

  1. 按春夏秋冬画十二格，纵向圈出三组。
  2. 解释“未己丁乙”的三个来源，不只报答案。
  3. 展开甲寅、丙午、辛丑、壬申四柱地支。
  4. 接上题，哪些藏干透出？辛日主有无同干根线索？
  5. 向别人用三句话介绍三组，再写出口诀不能覆盖的地方。
展开逐题答案与理由
  1. 春寅卯辰、夏巳午未、秋申酉戌、冬亥子丑；第一列四生，第二列四旺，第三列四墓库。理由是每季同位置取一支。
  2. 未夏末：阴土本气己、夏火余气丁、木库乙。未是木的墓库位置，故不是只含火土。
  3. 寅甲丙戊、午丁己、丑己癸辛、申庚壬戊；依次用四生、四旺例外、四库、四生规则。
  4. 四天干甲丙辛壬均见于支内：寅透甲丙，丑透辛，申透壬，午丁己未透。丑藏辛，有同干根线索；仍不能单独定强弱。
  5. 示例：四生是寅巳申亥，对应四行长生位置；四旺又叫四正，是卯午酉子；四墓库是辰未戌丑，土本气兼季末余气和库气。须补午藏己、亥不藏戊、巳表序丙戊庚；十干隔两格不能用于全部藏干。

整盘迁移 5 分

命盘：戊辰　乙卯　丁亥　辛丑

  1. 写出四支全部藏干。
  2. 哪些藏干在四柱天干中透出？
  3. 丁日主是否在地支见同类丁火？
  4. 能否因“无丁根”直接判定日主弱？
  5. 写一段只陈述结构、不越级断旺衰的分析。
展开完整参考答案
  1. 辰：戊乙癸；卯：乙；亥：壬甲；丑：己癸辛。
  2. 戊、乙、辛透出；癸、壬、甲、己未透。
  3. 四支藏干中没有丁，因此没有丁火同类根的直接线索。
  4. 不能。旺衰还要综合月令、其他生扶克泄、组合及具体口径。
  5. “日主为丁。四支展开为辰戊乙癸、卯乙、亥壬甲、丑己癸辛；天干透戊、乙、辛。支内未见丁火同类。以上是结构事实，尚不足以单独判定身强身弱。”

统一评分、复测与输出

40题，每题1分。书写题必须结论与理由都正确。36–40分达标，且第11–14题的规则边界与第37–39题的透干、根气判断须正确；30–35分重做错题组，低于30分重画四季图与藏干表。

错1–5、16：复习名称；错6–10、17：重画干圈；错11–15：写规则适用范围与反例；错18–20、21–35：按规则展开后查表；错36–40：逐字比对藏干和明干。24小时后遮表填十二格，48小时后换一组柱位标透干；尤其检查午己、亥无戊、巳丙戊庚表序。

本课输出：四季藏干图、午／亥／巳例外卡，以及一张标明藏干、透干与同类根线索的命盘结构表。不据此直接断旺衰或吉凶。

本课教学干支组合未据真实出生时刻核历法。藏干表采用主气在前口径，不赋固定权重。干圈与季节比喻是助记法，不冒充原典证明。原典对读：《渊海子平》地支藏遁歌。
