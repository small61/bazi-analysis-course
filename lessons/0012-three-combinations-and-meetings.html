Lesson 0012 · 55–65 分钟 · 20 题

三合与三会：生旺墓链和四季三格

先定义、再推导；把助记、结构事实与作用判断分清楚，用练习形成可核对的输出。

知识地图

第四课生旺墓 → 三合四组
第三课季节三格 → 三会四组
成员齐全与缺字 → 记录结构
季节、位置、力量 → 保留成局成化复核

先解释“三、合、会、局”

三指三个不同地支；三合按生、旺、墓库三个位置连接同一五行，三会按一个季节连续三个月连接。局在本课指组合组名与目标五行，不保证已经形成有效气势，更不保证合化。名称相近，取成员的路径却不同。

先修第三、四、十一课。常见表有木火金水四个三合组、木火金水四个三会组；土不单列独立季节三会。不同流派对成局、半合、拱合和化气条件有差异，本课只统一完整成员识别。

三合：回到第四课的生旺墓

木：亥 → 卯 → 未
火：寅 → 午 → 戌
金：巳 → 酉 → 丑
水：申 → 子 → 辰

每行依次为生、旺、墓库。比如水长生申、旺子、归库辰，称申子辰三合水组。这里沿用第四课常见阳干定位，不替代阴干十二长生排法。

先记旺点“卯午酉子”对应木火金水，再向两边挂生点和库点。十二支圈里每组三个支相隔四格：亥走四格到卯，再四格到未。数移动格，不含起点；圈末回环。

例：亥卯未是木组。反例：亥卯辰不是木组三合；辰是春季末，却不是木库。

三会：回到第三课的四季

春木：寅 → 卯 → 辰
夏火：巳 → 午 → 未
秋金：申 → 酉 → 戌
冬水：亥 → 子 → 丑
三会不跳格，一季三月连起来；三合跳四格，串生旺墓。记“会是一季，合是一链”。这是检索法，不证明组合一定起作用。

例：寅卯辰是三会木组；亥卯未是三合木组。都以木命名，成员不同。辰在三会中连接春季，在三合水组中为水库，不能只给辰贴单一目标五行。

齐全、缺字、重复：三个不同问题

原局三成员都出现，先写“某组成员齐全”，并列位置。只有两字，写“缺某字”，不偷偷补第三字。两次出现同一字不等于两个不同成员：申申子仍缺辰。

常见术语“半合”通常讨论生旺或旺墓两支关系；“拱合”常讨论生墓缺旺的组合，具体承认条件有分歧。本课不把任意两字都当完整三合，也不采用“缺字自动存在”的规则。

原局只有申子，后来某流年见辰：分别记录原局申子缺辰、该流年加入辰后出现完整成员条件。时间层不是原局事实，不能把流年辰永久塞回原盘。

完整成员不等于已经合化

  1. 先分清三合或三会，逐字查表。
  2. 记录成员柱位和重复，查有无缺字。
  3. 标与六合、六冲交叠的关系，保留全部事实。
  4. 回到月令、原藏干、根气与透干证据；写气势倾向和待复核条件，不把原干支抹掉。

迁移例：年申、月子、日辰、时午：申子辰水组三合成员齐全，同时月子与时午六冲；只说明成员与交叠，不判水组已化或午冲已消失。此为单层位置练习，非已核历法出生盘。

识别题 5分，每题1分

1. 哪组是三会木？

2. 申子辰三合的目标行？

3. 申申子是否三个成员齐全？

4. 亥卯未按什么结构记？

5. 完整成员出现后应先写什么？

推导题 5分，每题1分

  1. 从酉旺点还原三合金组。
  2. 用季节三格还原三会水组。
  3. 从寅顺行四格两次，得哪组三合？
  4. 木的三合与三会各写一组，说明差别。
  5. 辰为何既在春会木组，又在三合水组？
展开逐题答案与理由
  1. 金生巳、旺酉、库丑，得巳酉丑；相隔四格可校验。
  2. 冬季亥子丑，连续三个冬月，故三会水。
  3. 寅→午→戌，火生旺墓链；每步移动四格不计起点。
  4. 三合亥卯未按生旺墓；三会寅卯辰按春季三月。
  5. 两个组用不同关系：季节位置与生旺墓位置；并不改变辰原藏干戊乙癸。

纠错题 5分，每题1分

  1. “巳午未是三合火。”纠错。
  2. “申子缺辰，脑中补辰即可按水局。”纠错。
  3. “三会木齐了，辰里戊癸可删。”纠错。
  4. “流年辰来到，原局永远有辰。”纠错。
  5. “同样木组，三合三会成员无所谓。”纠错。
展开逐题答案与理由
  1. 巳午未是夏季三会火；三合火是寅午戌。
  2. 记录缺辰，不补原局不存在的字；半合或拱合条件另学。
  3. 成员齐全不等于合化，保留辰戊乙癸与待复核作用。
  4. 流年为独立时间层，只在所述时段加入考察，不能改写原局。
  5. 定义与成员不同，必须查各自完整表。

迁移题 5分，每题1分

  1. 年亥月卯日未时酉，列本课完整组及十一课六冲。
  2. 年寅月卯日辰时亥，有什么完整三会？
  3. 原局两支巳酉，再见流年丑怎样分层写？
  4. 四支申子午戌，水组三合缺什么？
  5. 用两句话说明成员事实与作用判断。
展开逐题答案与理由
  1. 亥卯未三合木成员齐全；月卯与时酉六冲。合冲交叠须保留。
  2. 寅卯辰三会木；另寅亥六合，不能混成另一个三会。
  3. 原局巳酉缺丑；该流年丑加入后金组三合成员条件齐全，尚未评估成化。
  4. 缺辰；子午冲已存在，但不因此凭空补辰或删子。
  5. 列组名、各成员位置和缺字；再列月令、透干、力量、合冲交叠等待复核项，不保证已化。

评分、复述与间隔复测

20题，每题1分；书写题结论和理由都正确才得分。18–20分达标，且第11–15题的边界纠错须全对；15–17分先重做错题组；低于15分重画关系图。

错1–5回术语与表；错6–10重走记忆结构；错11–15写一条正确规则及一个反例；错16–20补位置、时间层与未确认条件。24小时后遮表复述，48小时后换成员或例子再做迁移。

一分钟闭卷复述：说明本课术语、表的结构、记忆方式、适用范围及一个不能推出的结论。只会报名称、无法给理由时，不算掌握。

本课输出：三合／三会八组对照卡，一份标齐全、缺字和时间层的清单。

本课采用明确写出的常见子平关系表，不统一未说明的作用权重。助记图是检索工具，不冒充自然规律或原典证明；单层或局部条件例题非已核历法出生盘。原典对读：《渊海子平》干支组合相关篇目。传统解释不保证现实预测，不能替代医疗、法律或投资判断。
