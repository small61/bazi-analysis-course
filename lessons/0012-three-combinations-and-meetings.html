Lesson 0012 · 55–65 分钟 · 20 题

三合与三会：先认成员，再记位置

从熟悉的四季和十二支顺序出发；先学分组，不跳到高级作用判断。

知识地图：本课只做关系识别

第3课：四季月支 → 三会（连续三个）
十二支顺序 → 三合（固定隔四步）
第11课：记录关系和柱位 → 查齐全、缺字、交叠
第13课：增加刑害破标签 → 第14课：回看旺衰证据

前置知识只有十二支顺序、四季月支、第11课的六合六冲。第四课只需会查藏干表，不要求掌握高级术语。学完能列八组成员、区分两种组法，并写清哪些字实际出现。

先把“三合、三会”当作两张分组表

三合是传统规定的四组三支关系；三会是把同一季节的三个地支归为一组。三指三个不同成员，合、会是关系名称。每组以木、火、金、水之一命名，称“木组”等即可。此处组名不改变单个地支的五行或藏干。

本课程先采用下表做成员识别。书上常写“某某局”，本课只把它读作组名，不据此认定实际力量。不同流派对关系实际作用的条件有分歧，本课不建立作用优先级。

第一步：从已经学过的四季读出三会

例如春季寅卯辰称三会木组。辰仍是土支，仍藏戊乙癸；“木组”是三字关系的名称，不是把辰改成木支。土没有独立的第五个季节，本表不另设三会土组。

正例：巳午未是三会火组。反例：寅午戌跨三个季节，不能叫夏季三会。

第二步：三合先查固定表，再用数格法记住

组名三合成员对照：三会成员
木组亥、卯、未寅、卯、辰
火组寅、午、戌巳、午、未
金组巳、酉、丑申、酉、戌
水组申、子、辰亥、子、丑

走一遍水组：申 → 酉(1) → 戌(2) → 亥(3) → 子(4)；子 → 丑(1) → 寅(2) → 卯(3) → 辰(4)。只数移动，不把起点算第一步；经过亥后接子。辰再走四步回申。

先记三会“一季三个相邻字”，再记三合“顺序环上每隔四步取一个”。木火金水四组分别以卯午酉子作记忆锚点；锚点用于检索，不说明力量。起点可换，卯未亥与亥卯未是同组；命盘柱位也不必按口诀先后排列。

反例：亥卯辰不是三合木组，因为木组第三个成员应为未。不能看见春季的辰就补进木组三合。

三套问题分开，暂不靠高级概念推导

你在问什么？查什么？本课的边界
某支在一季第几个月？四季图：季首寅巳申亥、季中卯午酉子、季末辰未戌丑旧课常称四生、四旺、四墓库；这里用月序即可
哪些三支属于同一关系组？本课三合、三会表固定成员识别，不由季末推某行的库
某天干遇某地支，处于哪个传统阶段？十二长生体系须先说明参照天干、阴阳顺逆与土的口径，留待进阶

十二长生是一套传统十二阶段名称，其中有“长生”和“墓”。季节分类与阶段表的参照不同，不能仅凭“四生”认定某支本气在此长生，也不能凭“春末”推出木的墓。本课不使用十二长生解释三合。

“余气、库气”是旧课解释藏干时用到的名称，本课直接保留已知藏干表，不把它们作为新规则的前提。“半合、拱合”涉及两字关系的细分，“合化”指在特定口径与条件下讨论向某五行转化的作用判断；这些高级内容留待专课，不作为本课答题条件。认出三合不等于已经发生转化。

第三步：在实际给出的字里找成员

  1. 写清输入：原局地支及年、月、日、时位置。
  2. 分别对照两张表，逐字勾选；三个不同成员都出现才写“成员齐全”。
  3. 只有两字就写“缺某字”；重复字不能代替缺字。
  4. 再查第11课的六合六冲，有交叠就同时保留，不删字。
输入（均为地支位置练习，未核出生历法）可核对的记录
年申、月子、日辰、时午三合水组：年申、月子、日辰齐全；月子与时午六冲。尚未判断实际作用。
年申、月申、日子、时午水组只见申子，缺辰；两个申不能代替辰。
年未、月亥、日卯、时酉三合木组齐全，虽柱位顺序不同；日卯与时酉冲也保留。

时间层只做预告：原局指出生四柱；流年指所考察年份的干支输入。原局只有申子、某年另见辰，就分两行记“原局缺辰”“该年加入辰后三字齐”。流年排法以后再学，不能把后来输入永久写回出生四柱。

有哪几个字？ → 对照哪张表？ → 齐全还是缺字？
→ 分别在哪一柱？ → 有无已学合冲交叠？ → 保留待查作用

动手记：遮表、补字、立即自查

下面练习不计入20题总分。先口述缺字和组名，再展开答案。答错就回对应表，不以记忆故事解释力量。

三合：巳、？、丑

酉；三合金组。巳向前四步到酉。

三会：申、酉、？

戌；秋季三会金组，连续三个月。

子；冬季三会水组，连续三个月。

纸上画十二格，把同组三合的三个字连成三角形；换起点再数一次。第二遍只给木火金水组名，闭卷写三合／三会两列。图是助记，不是原典证明。

识别题 5分，每题1分

1. 哪组是三会木？

2. 申子辰三合的目标行？

3. 申申子是否三个成员齐全？

4. 亥卯未属于哪类分组？

5. 完整成员出现后应先写什么？

推导题 5分，每题1分

  1. 以酉为起点，每次走四步，还原三合金组。
  2. 用季节三格还原三会水组。
  3. 从寅顺行四格两次，得哪组三合？
  4. 木的三合与三会各写一组，说明差别。
  5. 辰为何既在春会木组，又在三合水组？
展开逐题答案与理由
  1. 酉→丑→巳，按常见表序写巳酉丑；每步移动四格，不含起点。
  2. 冬季亥子丑，连续三个冬月，故三会水。
  3. 寅→午→戌，是三合火组；每步移动四格不计起点。
  4. 三合亥卯未按固定成员表识别，可用隔四步助记；三会寅卯辰按春季三月。
  5. 三会按春季连续月支取组；三合按另一张固定表取组。不能由季末推三合组名，辰仍藏戊乙癸。

纠错题 5分，每题1分

  1. “巳午未是三合火。”纠错。
  2. “申子缺辰，脑中补辰即可按水局。”纠错。
  3. “三会木齐了，辰里戊癸可删。”纠错。
  4. “流年辰来到，原局永远有辰。”纠错。
  5. “同样木组，三合三会成员无所谓。”纠错。
展开逐题答案与理由
  1. 巳午未是夏季三会火；三合火是寅午戌。
  2. 记录缺辰，不补原局不存在的字；两字关系的细分以后再学。
  3. 成员齐全不等于合化，保留辰戊乙癸与待复核作用。
  4. 流年为独立时间层，只在所述时段加入考察，不能改写原局。
  5. 定义与成员不同，必须查各自完整表。

迁移题 5分，每题1分

  1. 年亥月卯日未时酉，列本课完整组及十一课六冲。
  2. 年寅月卯日辰时亥，有什么完整三会？
  3. 原局两支巳酉，再见流年丑怎样分层写？
  4. 四支申子午戌，水组三合缺什么？
  5. 用两句话说明成员事实与作用判断。
展开逐题答案与理由
  1. 亥卯未三合木成员齐全；月卯与时酉六冲。合冲交叠须保留。
  2. 寅卯辰三会木；另寅亥六合，不能混成另一个三会。
  3. 原局巳酉缺丑；该流年丑加入后金组三合成员条件齐全，尚未判断实际作用。
  4. 缺辰；子午冲已存在，但不因此凭空补辰或删子。
  5. 列组名、各成员位置和缺字；保留已学月令、藏干、根与合冲证据；作用未知就标待查，不改原干支。

评分、复述与间隔复测

20题，每题1分；书写题结论和理由都正确才得分。18–20分达标，且第11–15题的边界纠错须全对；15–17分先重做错题组；低于15分重画关系图。

错1–5回两张分组表；错6–10重走四季图与顺序环；错11–15写一条正确规则及一个反例；错16–20补位置、时间层与未确认条件。24小时后遮表复述，48小时后换成员或例子再做迁移。

一分钟闭卷复述：说明本课术语、表的结构、记忆方式、适用范围及一个不能推出的结论。只会报名称、无法给理由时，不算掌握。

本课输出：三合／三会八组对照卡，一份标齐全、缺字和时间层的清单。
